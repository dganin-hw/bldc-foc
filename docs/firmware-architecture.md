# Архитектура прошивки

Целевой МК: STM32G431 на основной плате, **один МК на один мотор**. Тулчейн:
CubeMX для инициализации периферии + собственный код FOC поверх LL/HAL. Сборка -
CMake + arm-none-eabi-gcc, отладка - внешний ST-Link (отладчика на плате нет).

Тот же CMake собирает `src/foc/` под хост - для симулятора и тестов. См.
[../firmware/README.md](../firmware/README.md).

---

## Бюджет времени - главное ограничение

ШИМ 48 кГц → период **20.8 мкс**. В него должно уложиться всё:

| Шаг | Оценка |
|---|---|
| Чтение АЦП (injected, результат уже в регистрах) | ~0 |
| Пересчёт токов, Кларк, Парк | 1-2 мкс |
| Наблюдатель + PLL | 3-5 мкс |
| Два PI + ограничение вектора | 1 мкс |
| Обратный Парк/Кларк + SVPWM | 1-2 мкс |
| Запись CCR | ~0 |
| **Итого** | **6-10 мкс, ~40% загрузки** |

Остальное - DShot, телеметрия, защиты, фон. Запас есть, но не бесконечный.
Поэтому: CORDIC вместо таблиц, никаких делений в цикле, замер времени пином на
осциллографе как постоянная практика.

Если не влезает - контур тока можно считать через период (24 кГц) при ШИМ 48 кГц.
Это запасной ход, не первый выбор.

## Два уровня исполнения

```
┌─ прерывание ADC (48 кГц, высший приоритет) ───────────┐
│  весь шаг FOC + наблюдатель                           │
│  без malloc, без ожиданий, без printf                 │
└───────────────────────────────────────────────────────┘
┌─ прерывания среднего приоритета ──────────────────────┐
│  DShot: приём кадра, ответ eRPM                       │
└───────────────────────────────────────────────────────┘
┌─ фоновый уровень ─────────────────────────────────────┐
│  контур скорости, машина состояний, arm/disarm        │
│  телеметрия по UART+DMA, защиты, температура          │
└───────────────────────────────────────────────────────┘
```

FreeRTOS на ESC не нужна и скорее вредна: задач мало, а джиттер критичен.
Она уместна, если дело дойдёт до своего полётного контроллера.

Обмен между уровнями - структура с `volatile` полями, для многобайтных величин
двойная буферизация.

## Периферия

| Блок | Настройка |
|---|---|
| TIM1 | center-aligned, CH1/2/3 + CH1N/2N/3N, dead-time через BDTR, ARR = fclk/(2·48кГц) |
| TIM1 BRK | nFAULT драйвера → аппаратное отключение выходов, минуя софт |
| TIM1 TRGO | update → триггер АЦП |
| ADC1/ADC2 | injected group по триггеру TIM1: 3 тока + Vbat + NTC |
| TIM4 | input capture + DMA для приёма DShot600 на PB6, он же для ответа |
| DMA | SPI, DShot, UART TX |
| SPI | энкодер (только на стенде), конфигурация DRV8323 |
| GPIO | enable драйвера, светодиод, пин замера времени цикла |
| IWDG | сторожевой |

Приоритеты NVIC: ADC (FOC) - 0, DShot - 1, UART - 3+.

## Машина состояний

```
INIT → CALIBRATE_ADC → IDLE ⇄ ARMED → ALIGN → RAMP → RUN
                        ↑                              │
                        └──────── DISARM ──────────────┤
                                                       ▼
                                                     FAULT
```

- `CALIBRATE_ADC` - ШИМ выключен, усреднение нулей токовых каналов
- `IDLE` - выходы в Z, ждём DShot
- `ARMED` - сигнал есть, газ на нуле, готовы стартовать
- `ALIGN` → `RAMP` → `RUN` - процедура sensorless-старта ([теория, §12](foc-theory.md))
- `FAULT` - выходы в Z, причина запомнена, выход только через disarm

Причины fault: превышение тока, недо/перенапряжение батареи, авария драйвера,
срыв наблюдателя, перегрев, **потеря сигнала DShot** (failsafe).

На стенде с энкодером добавляется `ALIGN_ENCODER` - калибровка нуля датчика.

---

## Failsafe

Пропала связь по DShot дольше заданного таймаута → плавное снижение до нуля и
disarm. Не резкая остановка: в полёте резкий сброс одного мотора опаснее плавного.
Таймаут порядка 100-250 мс.

Это обязательная функция, а не украшение: без неё потеря сигнала = неуправляемый
аппарат.

## Телеметрия

Два потока:

1. **eRPM обратно по линии DShot** (bidirectional) - для RPM-фильтрации в Betaflight
2. **UART** - напряжение, ток, ёмкость, температура, обороты. Формат KISS/BLHeli,
   чтобы FC понимал штатно; плюс расширенный бинарный кадр для своего скрипта на ПК
   (`id`, `iq`, оценённый угол, ошибка наблюдателя) - им настраиваются регуляторы

## Правила для кода в прерывании

- только float (FPU) или Q15/Q31 - никаких double
- никаких делений там, где можно умножить на предвычисленную обратную
- `sin`/`cos` - CORDIC
- ни одного вызова, время которого не ограничено сверху
- пин `GPIO_TIMING` в начале и конце - постоянный контроль загрузки
- «freeze timer on halt» в DBGMCU включён: при остановке ядра счётчик TIM1 встаёт,
  а выходы отключаются как при сброшенном MOE (уровень задают OSSI и GPIO).
  Без этого на брейкпоинте ШИМ продолжит работать с последней скважностью без
  контура тока. Поведение выходов проверить осциллографом

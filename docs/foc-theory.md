# Теория FOC: рабочая шпаргалка

Всё, что нужно, чтобы написать FOC. Формулы даны в том виде, в каком они лягут
в код.

---

## 1. Идея

В обмотках трёхфазного мотора ток создаёт магнитное поле - вектор в плоскости
статора. Ротор - постоянный магнит со своим вектором. Момент максимален, когда
поле статора перпендикулярно полю ротора.

FOC = «держи вектор тока статора под 90° к ротору и управляй его длиной».

Чтобы это делать регуляторами, вектор тока переводят в систему координат,
вращающуюся вместе с ротором (d-q). Там переменные становятся **постоянными**, и
обычный PI-регулятор с ними справляется.

- **d** (direct) - вдоль поля ротора. Момента не даёт, только греет. Задание `id* = 0`.
- **q** (quadrature) - перпендикулярно. Именно он даёт момент: `T = 3/2 · p · λm · iq`.

Итого: **задание момента = задание iq**.

---

## 2. Углы

```
θ_el = p · θ_mech        p - число пар полюсов
ω_el = p · ω_mech
```

Для gimbal-мотора 2804 обычно p = 7 (14 магнитов). Проверяется экспериментально:
провернуть ротор на полный механический оборот в open-loop и посчитать
электрические периоды.

Угол для Парка нужен **электрический**, отсчитанный от оси d ротора. Нулевую
точку даёт калибровка датчика (см. §8).

---

## 3. Преобразование Кларка (3 фазы → αβ)

При соединении звездой `ia + ib + ic = 0`, поэтому достаточно двух токов:

```
iα = ia
iβ = (ia + 2·ib) / √3
```

Это амплитудно-инвариантная форма (модуль вектора = амплитуде фазного тока).
Обратное преобразование:

```
va = vα
vb = (-vα + √3·vβ) / 2
vc = (-vα - √3·vβ) / 2
```

---

## 4. Преобразование Парка (αβ → dq)

```
id =  iα·cosθ + iβ·sinθ
iq = -iα·sinθ + iβ·cosθ
```

Обратное (для напряжений после регуляторов):

```
vα = vd·cosθ - vq·sinθ
vβ = vd·sinθ + vq·cosθ
```

`sin`/`cos` считать один раз на итерацию. На G4 - аппаратный CORDIC, на F4 -
таблица на 1024 точки с линейной интерполяцией или `arm_sin_cos_f32` из CMSIS-DSP.

Важно: угол для **обратного** Парка лучше брать с компенсацией задержки:
`θ_comp = θ + ω·(1.5·Ts)` - за время между измерением и приложением напряжения
ротор успевает провернуться. На высоких оборотах без этого падает момент.

---

## 5. Токовые PI-регуляторы

Два независимых: `id* = 0` и `iq* = задание`.

Объект по каждой оси - апериодическое звено первого порядка `1/(Ls + R)`.
Классическая настройка на полосу `ωc` (рад/с):

```
Kp = ωc · L
Ki = ωc · R
```

Полосу токового контура берут в 10-20 раз ниже частоты ШИМ:
при 20 кГц → `fc ≈ 1-2 кГц`, `ωc = 2π·fc`.

Дискретная реализация (Ts = 1/f_pwm):

```c
err  = ref - meas;
integ += Ki * Ts * err;          // накопитель
u     = Kp * err + integ;
if (u > umax) { u = umax; integ = clamp(integ, -umax, umax); }  // anti-windup
```

Ограничение - не по осям по отдельности, а по **модулю** вектора:
`sqrt(vd² + vq²) ≤ Vmax`. При превышении приоритет отдаётся `vd` (он нужен для
удержания поля), остаток отдаётся `vq`.

`Vmax = Vdc / √3` при SVPWM (без перемодуляции).

**[~] Decoupling** (развязка осей) - компенсация перекрёстных ЭДС:
`vd += -ω·L·iq`, `vq += ω·L·id + ω·λm`. Без него на высоких оборотах регуляторы
«тянут одеяло». Добавлять после того, как базовый контур заработал.

Контур скорости - снаружи, в 10-20 раз медленнее (1 кГц), его выход = `iq*`,
ограничен максимальным током.

## 6. SVPWM

Синусная модуляция использует только `Vdc/2` амплитуды. SVPWM даёт `Vdc/√3` -
на 15.5 % больше, за счёт того, что в все три фазы добавляется одинаковый сигнал
нулевой последовательности (на линейные напряжения он не влияет).

Простейшая корректная реализация - **min-max инъекция**, без разбора секторов:

```c
// va,vb,vc - из обратного Кларка, в вольтах
float vmax = max3(va, vb, vc);
float vmin = min3(va, vb, vc);
float voff = (vmax + vmin) * 0.5f;

duty_a = 0.5f + (va - voff) / Vdc;   // 0..1
duty_b = 0.5f + (vb - voff) / Vdc;
duty_c = 0.5f + (vc - voff) / Vdc;
```

Результат математически эквивалентен классическому SVPWM с симметричным
размещением нулевых векторов, но пишется в шесть строк и не имеет ветвлений.

Ограничения на скважность: минимальная длительность включения low-side нужна,
чтобы успеть измерить ток (см. §7), плюс dead-time «съедает» края. Практически
скважность зажимают в `[0.03 … 0.97]`.

---

## 7. Измерение тока

Три low-side шунта. Ток фазы через шунт течёт **только когда нижний ключ открыт**.
При center-aligned ШИМ все три нижних ключа гарантированно открыты в момент
**центра нулевого вектора** - это середина периода, то есть момент, когда счётчик
TIM1 доходит до вершины (или до нуля, смотря как настроен).

Отсюда схема: TIM1 в режиме center-aligned, событие TRGO по update → запуск
инжектированной группы АЦП → DMA → прерывание конца преобразования → шаг FOC.

Тонкости:
- **Калибровка нуля.** При старте, с выключенным ШИМ, усреднить 512 отсчётов
  каждого канала - это ноль (обычно ~Vref/2 для биполярного усилителя). Вычитать
  всегда.
- **Минимальное окно.** При скважности, близкой к 100 %, нижний ключ открыт слишком
  коротко - ток измерить нельзя. Отсюда зажим скважности; на этапе 3 - переход к
  реконструкции по двум фазам или сдвигу фаз ШИМ.
- **Сэмплировать быстро.** Время выборки + преобразования должно уложиться в
  плоскую часть, а не попадать на переходный процесс после коммутации.

Ток в амперах:

```
I = (adc_raw - adc_zero) * (Vref / 4096) / (Gain * Rshunt)
```

## 8. Датчик положения и его калибровка

Нулевую точку электрического угла надо найти один раз:

1. Подать постоянный вектор по оси d при `θ = 0` (то есть `vd = небольшое`, `vq = 0`)
2. Подождать 0.5-1 с - ротор физически провернётся и выровняется по этому вектору
3. Считанное в этот момент значение датчика = `offset`
4. Дальше `θ_el = wrap(p · (raw - offset) · 2π / N)`

Проверка знака: если при вращении вектора вперёд ротор идёт назад - поменять две
фазы местами или инвертировать направление счёта датчика.

---

## 9. Полный цикл управления (что происходит каждые 50 мкс)

```
1. АЦП отдал ia, ib, ic, Vdc          (по DMA, без ожидания)
2. вычесть нули, перевести в амперы
3. прочитать датчик → θ_mech → θ_el
4. Кларк:  ia,ib      → iα, iβ
5. Парк:   iα,iβ, θ   → id, iq
6. PI(d): id* - id    → vd
   PI(q): iq* - iq    → vq
7. ограничение модуля вектора
8. обратный Парк: vd,vq, θ_comp → vα, vβ
9. обратный Кларк: vα,vβ        → va, vb, vc
10. SVPWM (min-max)             → duty_a/b/c
11. записать в CCR1..3 TIM1
```

Бюджет времени: 50 мкс на всё. Реально шаг FOC на M4F с FPU - 3-8 мкс.
Замерять пином: `GPIO high` в начале обработчика, `low` в конце, смотреть
осциллографом.

---

## 10. Порядок ввода в строй (важнее самих формул)

1. **ШИМ без мотора.** Осциллограф на затворах: комплементарность, dead-time,
   центрирование. Мотор не подключён.
2. **Open-loop вращение.** Угол генерируется программно линейно, `vd = 0`,
   `vq = const`, регуляторов нет. Мотор должен вращаться синхронно. Питание 12 В,
   ток ограничен. Это проверяет ШИМ, SVPWM, порядок фаз.
3. **Измерение тока.** В open-loop смотреть на посчитанные `id/iq` - они должны
   быть примерно постоянными. Если «плавают» синусоидой - неверен угол или знак.
4. **Токовый контур при заторможенном роторе.** Задать `iq* = 0.5 А`, ротор зажат.
   Проверить по осциллографу, что реальный ток соответствует.
5. **Скачок задания.** Снять переходный процесс `iq`, настроить Kp/Ki.
6. **Отпустить ротор** → момент-режим. Потом контур скорости.

Каждый шаг записывать в протокол испытаний вместе с осциллограммой.

## 11. Модель мотора для симулятора

Нужна на этапе 0, чтобы отлаживать FOC до появления железа. Модель PMSM в тех же
dq-координатах, что и регуляторы - то есть буквально обращение формул выше.

**Электрика** (два дифура первого порядка):

```
did/dt = (vd - R·id + ω_el·Lq·iq) / Ld
diq/dt = (vq - R·iq - ω_el·Ld·id - ω_el·λm) / Lq
```

Для мотора с поверхностными магнитами (обычный gimbal) `Ld = Lq = L` - упрощается.
`λm` - потокосцепление магнитов, связано с kV: `λm ≈ 60 / (2π · kV · p · √3)`
(формула зависит от того, как производитель мерил kV, - проще определить `λm`
экспериментально по обратной ЭДС).

**Момент и механика:**

```
T  = 1.5 · p · λm · iq          (для Ld = Lq)
dω_mech/dt = (T - T_load - B·ω_mech) / J
dθ_mech/dt = ω_mech
```

`J` - момент инерции ротора, `B` - вязкое трение. Точные значения не важны: их
задача - дать правдоподобную динамику для настройки контура скорости.

**Интегрирование:** шаг Эйлера с `dt = Ts/10` (5 мкс) достаточно, если постоянная
времени обмотки `L/R` заметно больше шага. Для gimbal-мотора `L/R ≈ 1 мс` - запас
огромный.

**Что обязательно смоделировать, иначе симуляция врёт в свою пользу:**

| Эффект | Как | Зачем |
|---|---|---|
| Задержка на такт | приложить напряжение, посчитанное в прошлом периоде | из-за неё контур звенит на высокой полосе |
| Квантование АЦП | округлить ток до 12 бит от полной шкалы | видно, какое разрешение реально нужно |
| Шум АЦП | ±1-2 LSB белого шума | проверка, не слишком ли агрессивен Kp |
| Квантование энкодера | округлить угол до 14 бит | влияет на оценку скорости |
| Ограничение Vdc | зажать модуль вектора | иначе регулятор «выезжает» на несуществующем напряжении |
| Dead-time | вычесть из скважности мёртвое время со знаком тока | искажение на малых токах, реальный эффект |

Последний пункт стоит отдельно: искажение из-за dead-time - самая заметная разница
между «идеальной» симуляцией и реальным мотором. Если он смоделирован, на железе
не будет сюрприза.

## 12. Sensorless - оценка угла по обратной ЭДС

На дрон-мотор датчик не поставишь, поэтому угол приходится вычислять. Идея: в
уравнениях мотора всё известно, кроме ЭДС магнитов, а она напрямую содержит угол.

### Наблюдатель потокосцепления (простой вариант)

Интегрируем напряжение за вычетом падения на сопротивлении:

```
λα = ∫(vα - R·iα) dt
λβ = ∫(vβ - R·iβ) dt
```

Вычитаем вклад индуктивности - остаётся поток магнитов:

```
λmα = λα - L·iα
λmβ = λβ - L·iβ
θ̂ = atan2(λmβ, λmα)
```

Проблема: чистый интегратор дрейфует от любого смещения нуля АЦП. Лечится заменой
на фильтр первого порядка с частотой среза сильно ниже рабочей электрической, с
компенсацией вносимого им сдвига фазы. Это главная практическая тонкость метода.

### SMO (наблюдатель со скользящим режимом)

Строим модель тока, сравниваем с измеренным, невязку подаём через разрывную
функцию - её эквивалентное значение и есть ЭДС:

```
di̇̂/dt = (v - R·î - z) / L,   z = k·sign(î - i)
```

`z` после фильтрации даёт `eα, eβ`, откуда `θ̂ = atan2(-eα, eβ)`.
Устойчивее к неточности параметров, но требует фильтрации и компенсации фазы.

### PLL - обязательная надстройка

`atan2` шумит и не даёт скорости. Поверх ставится PLL:

```
err = -eα·cos(θ̂) - eβ·sin(θ̂)      // ошибка фазы
ω̂  += Ki_pll · err · Ts            // PI
θ̂  += (ω̂ + Kp_pll · err) · Ts
```

Выход - гладкий угол и скорость. Полосу PLL берут заметно ниже минимальной
рабочей электрической частоты.

### Старт - отдельная задача

При нулевой скорости ЭДС нет, наблюдатель слеп. Последовательность:

1. **Выравнивание:** подать вектор по d, ротор встаёт в известное положение
2. **Open-loop разгон:** крутить угол программно с нарастающей частотой, ток
   задавать током, а не углом
3. **Переход:** когда амплитуда оценённой ЭДС превысила порог и оценка угла
   стабилизировалась - переключиться на наблюдатель, с гистерезисом
4. **Срыв:** если оценка разошлась - обратно в open-loop или в аварию

На дроне это происходит при каждом arm, поэтому старт должен быть надёжным и
быстрым - это отдельная работа, не «допилим потом».

### Как отлаживать

Только на моторе с энкодером. Наблюдатель считает угол, энкодер даёт истинный,
разница пишется в телеметрию и строится на графике: **ошибка оценки в градусах**
на разных оборотах и токах. Без такого стенда наблюдатель настраивается гаданием.

## 13. Особенности высоких электрических частот (дрон)

Мотор 2207 с kV 1800 на 4S: ~30000 об/мин, 7 пар полюсов → **3.5 кГц**
электрической частоты. Отсюда три следствия, которых нет на медленном моторе.

**ШИМ 48 кГц вместо 20.** При 20 кГц на электрический период приходится 6 шагов
управления - управлять нечем. При 48 кГц ~14, и это уже минимально приемлемо.
Бюджет времени на весь цикл - 20 мкс.

**Компенсация задержки становится критичной.** Поправка `θ_comp = θ + ω·1.5·Ts`
при `ω_el = 2π·3500 = 22000 рад/с` и `Ts = 20.8 мкс` даёт **0.69 рад ≈ 40°**.
Без неё вектор тока уезжает почти на половину прямого угла, и момент падает в разы.
На медленном моторе этой поправкой можно пренебречь, здесь - нельзя.

**Полоса токового контура упирается в потолок.** При 48 кГц ШИМ разумный максимум
полосы - около 5 кГц, то есть на максимальных оборотах она лишь немного выше
электрической частоты. Это фундаментальное ограничение, а не недоработка: качество
регулирования на максимуме неизбежно деградирует. Реальные ESC с этим живут.

Практический вывод: коэффициенты, настроенные на gimbal-моторе, к дрон-мотору
не относятся никак. Настраивать заново, и обязательно прогнать модель на
параметрах дрон-мотора перед железом.

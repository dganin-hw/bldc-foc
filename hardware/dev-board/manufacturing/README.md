# Файлы для производства основной платы

Здесь всё, что нужно, чтобы заказать голую плату, купить детали и собрать её.

## Параметры платы

| Параметр | Значение |
|---|---|
| Размер | 108 × 81 мм, контур по оси линии `Edge_Cuts` |
| Слои | 4: `F_Cu`, `In1_Cu`, `In2_Cu`, `B_Cu` (сверху вниз) |
| Материал и толщина | FR-4, 1,6 мм |
| Медь | наружные слои 1 oz (35 мкм), внутренние 0,5 oz (18 мкм) |
| Покрытие | ENIG |
| Маска | зелёная, с двух сторон |
| Маркировка | белая, с двух сторон |
| Контроль импеданса | не нужен |
| Минимальный проводник и зазор | 0,20 / 0,20 мм |
| Медь от края платы | не ближе 0,50 мм |
| Металлизированные отверстия | 359: 300 переходных Ø0,30 мм, 25 под U2 Ø0,20 мм, 34 под выводы Ø1,0-1,3 мм |
| Отверстия без металлизации | 4 монтажных Ø3,20 мм |
| Переходные отверстия | площадка Ø0,60 мм, отверстие Ø0,30 мм, закрыты маской с двух сторон |

Подойдёт типовая четырёхслойная структура 1,6 мм с указанной медью. Габарит в
Gerber может определиться как 108,05 × 81,05 мм: это контур вместе с толщиной линии,
готовая плата 108 × 81 мм.

## Главное требование: площадка U2

Под драйвером U2 матрица 5 × 5 сквозных отверстий Ø0,20 мм (площадки Ø0,50 мм,
шаг 1 мм).

- **Сверху** площадка 5,15 × 5,15 мм открыта (окно маски 5,23 × 5,23 мм) вместе с
  устьями отверстий.
- **Снизу** вся площадка и все 25 устьев закрыты маской, как в `B_Mask`.
- Нужно именно закрытие маской снизу, а не заполнение смолой, заглушки или
  via-in-pad с медной крышкой.

Если завод не может надёжно закрыть снизу отверстия Ø0,20 мм при открытой верхней
площадке, это нужно выяснить до изготовления.

## Текст для комментария к заказу

```text
Голые печатные платы, без монтажа. FR-4, 4 слоя, готовая толщина 1,6 мм.
Медь: наружные слои 1 oz, внутренние 0,5 oz. Контроль импеданса не требуется.
Покрытие ENIG. Маска зелёная с двух сторон, маркировка белая с двух сторон.
Gerber и Excellon в мм, общая система координат, нижние слои не зеркалить.
Контур фрезеровать по оси линии Edge_Cuts, готовый размер 108 × 81 мм.
Маска уже расширена в Gerber на 0,04 мм, повторно не расширять.
Переходные отверстия Ø0,30 / площадка Ø0,60 мм закрыты маской с двух сторон.
U2: 25 отверстий Ø0,20 мм в тепловой площадке. Сверху площадка открыта,
снизу площадка и отверстия закрыты маской (tenting), не заполнять и не закрывать медью.
Монтажные отверстия Ø3,20 мм без металлизации.
Топологию, отверстия и маску без согласования не менять.
```

## Что в папке

| Путь | Что внутри |
|---|---|
| [`gerbers/`](gerbers/) | медь (4 слоя), маска, маркировка, контур, паста верхней стороны для трафарета, `.gbrjob` |
| [`drill/`](drill/) | сверловка Excellon отдельно для PTH и NPTH, карты сверловки в PDF, отчёт |
| [`bom/BOM.csv`](bom/BOM.csv) | перечень компонентов: 45 строк, 111 деталей, артикулы и коды LCSC |
| [`placement/component-map.csv`](placement/component-map.csv) | координаты, поворот и сторона каждого компонента |

На завод отправляются `gerbers/` и два файла `.drl` из `drill/`. Паста нужна, только
если заказывается трафарет.

## Перечень компонентов

- 109 позиций схемы, все на верхней стороне. 36 контрольных площадок и 4 отверстия
  входят в рисунок платы и не покупаются.
- F1 занимает в перечне две строки: вставка Eaton BK1/S501-2-R и две клипсы
  Littelfuse 01110005MR.
- JP1, JP2 и J6 - одинаковые штыревые разъёмы 1×2. Для JP1 и JP2 нужны ещё две
  перемычки-джампера с шагом 2,54 мм, в перечень они не входят.
- Наличие и цены нужно проверить в момент заказа.

## Координаты

В `component-map.csv` координаты отсчитываются от левого верхнего угла платы:
X вправо, Y вниз, в миллиметрах. Угол поворота как в KiCad.

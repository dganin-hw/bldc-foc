# Файлы для производства платы энкодера

## Параметры платы

| Параметр | Значение |
|---|---|
| Размер | 32 × 28 мм, фаски 1 × 1 мм на четырёх углах, контур по оси линии `Edge_Cuts` |
| Слои | 2: `F_Cu`, `B_Cu` |
| Материал и толщина | FR-4, 1,6 мм |
| Медь | 35 мкм с каждой стороны |
| Покрытие | ENIG |
| Маска | зелёная, с двух сторон |
| Маркировка | белая, с двух сторон |
| Контроль импеданса | не нужен |
| Минимальный проводник и зазор | 0,20 / 0,20 мм |
| Металлизированные отверстия | 24 переходных Ø0,30 мм, площадка Ø0,60 мм |
| Отверстия без металлизации | 4 монтажных Ø2,20 мм на сетке 24 × 20 мм |

В центре платы под датчиком отверстий нет, добавлять их нельзя.

## Текст для комментария к заказу

```text
Голые печатные платы, без монтажа. FR-4, 2 слоя, готовая толщина 1,6 мм,
медь 35 мкм. Контроль импеданса не требуется. Покрытие ENIG.
Маска зелёная с двух сторон, маркировка белая с двух сторон.
Gerber и Excellon в мм, общая система координат, нижние слои не зеркалить.
Контур фрезеровать по оси линии Edge_Cuts, готовый размер 32 × 28 мм.
Маска уже задана в Gerber, повторно не расширять.
Монтажные отверстия Ø2,20 мм без металлизации. Не добавлять отверстие в центре датчика.
```

## Что в папке

| Путь | Что внутри |
|---|---|
| [`gerbers/`](gerbers/) | медь, маска, маркировка, контур, паста для обеих сторон, `.gbrjob` |
| [`drill/`](drill/) | сверловка Excellon отдельно для PTH и NPTH, карты сверловки в PDF, отчёт |
| [`bom/BOM.csv`](bom/BOM.csv) | перечень компонентов: 7 строк, 8 деталей |
| [`placement/component-map.csv`](placement/component-map.csv) | координаты, поворот и сторона компонентов |

Все компоненты, кроме разъёма J1, стоят на стороне магнита. J1 стоит на обратной
стороне. Координаты в `component-map.csv` даны в системе KiCad, центр датчика U1 в
точке (100; 100) мм.
